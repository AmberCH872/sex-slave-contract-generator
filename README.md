# 性奴认主协议生成器 (BDSM Contract Generator) 📜

一个专业的 BDSM 契约协议 Web 应用，用于创建和生成各种类型的性奴认主协议。包含羞耻、淫荡、骚、下贱的专属内容！

## 🌟 功能特性

- **多种协议模板**：基本主奴、宠玩协议、24/7 全权交换、哥罗奴隶、女上位等
- **完全自定义**：编辑每一个字，添加专属条款
- **精美排版**：优雅的古典风格设计，支持打印和 PDF 导出
- **隐私保护**：所有数据本地处理，不上传云端
- **羞耻内容**：充满羞耻感、淫荡感的协议文本

## 🚀 快速开始

### 方式一：本地运行（推荐）

1. 安装 Node.js (https://nodejs.org/)
2. 进入项目目录并安装依赖：
   ```bash
   cd SexSlaveContractGenerator
   npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```
4. 打开浏览器访问 http://localhost:5173

### 方式二：部署到 GitHub Pages（在线使用）

#### 步骤 1：创建 GitHub 仓库

在 [GitHub](https://github.com/new) 上创建一个**公开**的新仓库，命名为 `sex-slave-contract-generator`。

#### 步骤 2：推送代码

```bash
# 初始化 Git（如果还没有）
git init

# 添加所有文件到暂存区
git add .

# 提交更改
git commit -m "Initial commit: BDSM Contract Generator"

# 关联远程仓库并推送
git remote add origin https://github.com/AmberCH872/sex-slave-contract-generator.git
git push -u origin main
```

#### 步骤 3：配置 GitHub Pages

1. 进入你的仓库设置 (Settings)
2. 在左侧菜单找到 **Pages**
3. 在 **Build and deployment** 下的 **Branch** 部分：
   - Branch: `main` (或 `master`)
   - Folder: `/root`
4. 点击 **Save**

#### 步骤 4：等待部署完成

大约 1-2 分钟后，你的网站就会上线！访问地址将是：
```
https://AmberCH872.github.io/sex-slave-contract-generator/
```
